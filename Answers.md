## Q1. Explain the Difference Between Merge and Rebase

**Merge** is used when we want to combine the work of two branches. For example, after completing development on a feature branch, we can merge it into the main branch. This keeps all commit history intact and creates a merge commit.

**Rebase** is used to update a branch with the latest changes from another branch. It moves the branch commits on top of the updated branch, resulting in a cleaner and more linear commit history.
